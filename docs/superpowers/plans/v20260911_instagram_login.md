# Instagram 登录
请使用 Python + Playwright 为我编写一个比特浏览器（BitBrowser）自动化多开并登录 Instagram 的工程脚本。

1. 核心技术栈
语言与库：Python 3.10+、Playwright (Async/Sync 均可，推荐 playwright.async_api)、aiohttp 或 requests。

2. 账号信息来源
读取D:\python_workspace\my_code\AutoMessage\instagram\ins_acct.md 再 Instagram 账号数据 里面 
先取第一条数据进行登录测试

3. 详细功能逻辑流程
针对列表中的每一个账号，执行以下步骤（需支持通过并发量限制同时启动的窗口数）：
启动比特窗口：调用 API POST [http://127.0.0.1:54345/browser/open](http://127.0.0.1:54345/browser/open) (payload: {"id": browser_id})，获取返回的 http (如 127.0.0.1:xxxx)。

Playwright 接管：使用 Playwright 的 chromium.connect_over_cdp(f"http://{http_address}") 连接已打开的比特浏览器环境，并获取/创建 context 和 page。
登录策略：
优先 Cookie 登录：解析 cookie_str（将 key=value 字符串解析为 Playwright 的 Cookie 对象数组：domain=".instagram.com", path="/", name, value），通过 context.add_cookies() 注入到浏览器。
导航至 [https://www.instagram.com/](https://www.instagram.com/)，等待页面加载。
登录状态检测：检查当前页面 URL 及关键元素（如是否存在个人主页图标或导航栏）。
降级/兜底账号密码登录：如果 Cookie 失效（页面停留在 /accounts/login/），自动触发账号密码登录流程：
模拟真实输入（模拟逐字打字延迟 type(..., delay=100)）填写 username 和 password。
点击登录按钮。
等待页面跳转，若触发二步验证（2FA）或验证码，在控制台打出告警，等待人工接管或等待超时。
结果输出与状态返回：记录每个 browser_id 的登录结果（成功 / 失败 / 需人机验证），并输出日志。

4. 代码结构要求
4.1 支持多个账号进行登录，测试阶段只是用第一个
